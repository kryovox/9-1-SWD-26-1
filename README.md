## Правила работы

1. До изменения файла создаём Issue с задачей и критериями готовности.
2. Назначаем одного исполнителя и пишем о начале работы.
3. В каждый момент один файл редактирует один участник.
4. Открываем актуальный файл, сохраняем понятный commit с номером Issue.
5. В карточку задачи добавляем ссылку на commit и пояснение результата.
6. Автор задачи проверяет критерии и закрывает завершённую Issue.

Текст для описания задач находится в [TASK_TEMPLATE.md](TASK_TEMPLATE.md).
