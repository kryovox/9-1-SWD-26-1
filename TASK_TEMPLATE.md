# Шаблон задачи

Скопируйте текст ниже в новую Issue и заполните поля.
Этот файл служит памяткой для ручного создания задач.

## Файл

Укажите один конкретный файл.

## Что нужно изменить

Опишите ожидаемый результат в одном или двух предложениях.

## Критерии готовности

- [ ] Указанное изменение внесено в нужный файл.
- [ ] Конкретный пример добавлен и читается.
- [ ] В комментарии есть ссылка на commit.

## Обсуждение

Исполнитель пишет о начале работы и уточняет вопросы в комментариях.
После изменения оставляет ссылку на commit и объясняет результат.
Автор задачи проверяет критерии и закрывает выполненную Issue.
